## Fait aujourd'huit 
Aujourd’hui, j’ai suivi le cours sur la documentation avec Git, GitHub et GitHub Pages.

Pendant le cours, j’ai découvert l’importance de bien documenter le travail réalisé dans un projet. Nous avons parlé de VSCode, Git, GitHub et GitHub Pages.

J’ai également découvert le langage Markdown et quelques règles simples pour écrire des titres, des listes, des liens, des images et du code.


## Appris 

 J’ai appris que la documentation ne doit pas être faite seulement à la fin du projet. Elle doit être réalisée régulièrement, de préférence chaque jour.

J’ai aussi appris que la documentation permet de garder une trace de ce que nous avons fait, de transmettre les informations aux autres membres de l’équipe et de montrer les différentes étapes du travail.

Concernant Git, j’ai retenu qu’il faut :
-   synchroniser le travail en arrivant ;
- faire les modifications ;
- indexer les modifications ;
- faire un commit avec un message clair ;
- synchroniser le travail en partant.
